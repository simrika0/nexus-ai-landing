# NexusAI — Premium Next.js AI SaaS Landing Page Template

A conversion-optimized, production-ready landing page template built specifically for AI startups, SaaS tools, and developers looking to ship fast.

## 🚀 Live Demo
[View Live Preview](https://nexus-ai-landing-yyzg.vercel.app)

## ✨ Features
- **Next.js 16 (App Router)** – Built on modern React standards with Turbopack support.
- **Tailwind CSS** – Fully responsive dark-mode UI with smooth utility classes.
- **Lucide React Icons** – Clean, lightweight iconography.
- **Conversion Focused** – Includes interactive hero sections, bento-grid feature highlights, and tiered pricing cards.
